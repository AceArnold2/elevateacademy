Web Development

Learn how websites work, then design, build, test and publish your own.

Enroll Register your interest

About this course

Every website you use is built from HTML, CSS and JavaScript. In this course, students learn how the web works and use those three languages to build real, working pages. Students learn by doing: short lessons, guided practice, then independent projects with feedback from the instructor.

Students finish with a website they built themselves, ready to show to family, schools and future employers.

Ages13 to 17
Beginner course4 weeks
Starting levelNo experience needed
FeeShared when you register

What students learn

  1. Web fundamentals

    How the internet and websites work, what browsers and servers do, and how HTML, CSS and JavaScript fit together. Setting up a code editor.

  2. HTML

    Page structure, headings, links, images, lists, tables and forms, written in a clean, meaningful way.

  3. CSS

    Colours, fonts, spacing and layout with Flexbox and Grid, plus pages that adapt to phones and laptops.

  4. JavaScript fundamentals

    Variables, conditions, loops, functions and events, and using them to make a page respond to the user.

  5. Practical web development

    Combining everything: menus, interactive elements, form checks, debugging, basic accessibility and publishing a site online.

Beginner students focus on HTML and building their first pages. CSS, JavaScript and larger projects build on this in the intermediate and advanced levels.

What students build

  • A personal portfolio website
  • A student profile or club website
  • A small business landing page
  • An interactive quiz
  • A simple calculator

Learning pathway

Students move up when they show they are ready, not just because of their age.

Beginner

HTML and building basic websites.

Intermediate

CSS, responsive layouts, JavaScript and interactive websites.

Advanced

Larger projects, working with APIs, version control and deployment.

Good to know

  • Equipment: a computer or laptop with an internet connection. We use free software only.
  • Online safety: every student completes our Online Safety foundation first.
  • Certificate: students who meet the attendance, participation and project requirements receive a completion certificate. It is not a professional accreditation.
